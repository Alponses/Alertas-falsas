Advertencia de laboratorio

No uses este simulador en tu dispositivo principal

Este proyecto genera scripts PowerShell diseñados para provocar detecciones reales en Microsoft Defender XDR, incluyendo EDR, AMSI, Network Protection, PUA, EICAR y comportamiento anómalo. Las pruebas pueden ser bloqueadas, puestas en cuarentena, registradas como incidentes o alterar temporalmente el entorno de prueba.

Usa únicamente:

  • Una VM, sandbox o equipo dedicado exclusivamente a laboratorio.
  • Un dispositivo sin archivos personales, credenciales ni información corporativa sensible.
  • Preferentemente una VM con snapshot para poder restaurarla después de las pruebas.
  • Un tenant y endpoint de prueba donde estés autorizado a generar alertas de Defender XDR.

No lo ejecutes en:

Tu PC personal principal, computadora de trabajo, servidores de producción, endpoints de usuarios reales o equipos con información importante.

Si estás en tu equipo principal, cierra esta página y abre el laboratorio desde una VM o equipo de pruebas.
